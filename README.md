# Confeti

App de iPad para que niñas y niños de 6 a 9 años practiquen el trazo de letras y números, con piñatas que se ganan con estrellas. Hecha como proyecto de servicio social para un Centro de Atención Múltiple.

- Trazo con el dedo de todo el alfabeto (con Ñ) y los números del 0 al 9, con ayuda que se ajusta sola.
- "Mi nombre": aprende a escribir su propio nombre letra por letra.
- Cuatro juegos: ¿Dónde está?, ¿Con qué empieza?, Escribe y Cuenta y traza.
- Álbum de 11 piñatas que se desbloquean con estrellas.
- Instrucciones habladas, sin límite de tiempo y compatible con Reducir movimiento.
- Todo funciona sin internet.

SwiftUI · iPadOS 17 o más nuevo · Xcode 26

Para instalarla en un iPad: [INSTALAR_EN_IPAD.md](INSTALAR_EN_IPAD.md).
